# BlockyBushes

BlockyBushes changes vanilla sweet berry bushes into full-block bushes with a stem growth stage and right-click harvesting.

The goal is to make berry bushes feel more natural and consistent while keeping vanilla mechanics simple and intuitive.

## Features

- **Stem growth stage**  
  Planting sweet berries places a stem instead of a bush.

- **Natural growth**  
  Stems grow into full berry bushes over time or when fertilized with bone meal.

- **Right-click harvesting**  
  Harvest berries without breaking the bush.

- **Full-block bushes**  
  Mature berry bushes are full blocks with a visible inner stem.

- **World generation support**  
  Naturally generated berry bushes start as full blocks.

## Inspiration

This mod is inspired by the berry bush design from [The Aether](https://modrinth.com/mod/aether).

The idea of berry bushes growing from stems and being harvestable without breaking them comes from The Aether.  
BlockyBushes is an independent implementation designed for vanilla gameplay and does not include any assets or code from The Aether.
